# Project Brief: CipherLink (AntiPiry)

## Название

CipherLink (AntiPiry)

## Цель

Кроссплатформенный E2EE мессенджер с дизайном Telegram Desktop.

## Стек

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Electron
- Capacitor

## Ключевые модули

- `src/services/cryptoService.ts` — основной сервис криптографии
- `src/crypto/signal/*` — реализация Signal Protocol
- `src/hooks/useWebSocket.ts` — WebSocket соединение
- `src/components/Layout.tsx` — главный лейаут приложения

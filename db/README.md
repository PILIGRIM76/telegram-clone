# Data Layer (База данных)

## Структура

```
db/
├── index.js           # Основной слой доступа к данным
├── migrate.js         # Утилита для миграций
├── migrations/
│   └── 001_initial_schema.sql  # Начальная схема БД
└── seeds/
    └── test_data.sql  # Тестовые данные
```

## Использование

### In-Memory хранилище (по умолчанию)
```javascript
const { db } = require('./db/index.js');

// Создание пользователя
await db.создатьПользователя({ публичныйКлюч: '...', приватныйКлюч: '...' });

// Получение пользователя
const user = await db.получитьПользователя('uid');
```

### SQLite (для production)
```bash
# Установка sqlite3
npm install sqlite3

# Установка переменной окружения
export STORAGE_TYPE=sqlite
export DB_PATH=./data/cipherlink.db

# Запуск миграций
node db/migrate.js up
```

## Методы слоя данных

### Пользователи
- `создатьПользователя(user)` - создать пользователя
- `получитьПользователя(uid)` - получить пользователя по UID
- `обновитьПользователя(uid, данные)` - обновить пользователя
- `удалитьПользователя(uid)` - удалить пользователя
- `получитьВсеПользователи()` - получить всех пользователей

### Группы
- `создатьГруппу(group)` - создать группу
- `получитьГруппу(id)` - получить группу по ID
- `удалитьГруппу(id)` - удалить группу
- `получитьВсеГруппы()` - получить все группы

### Сообщения
- `сохранитьСообщение(message)` - сохранить сообщение
- `получитьСообщение(id)` - получить сообщение по ID

### Офлайн-сообщения
- `добавитьОфлайнСообщение(uid, сообщение)` - добавить офлайн-сообщение
- `получитьОфлайнСообщения(uid)` - получить офлайн-сообщения

## Переключение между хранилищами

По умолчанию используется in-memory хранилище. Для использования SQLite:

1. Установите переменную окружения:
   ```bash
   STORAGE_TYPE=sqlite
   ```

2. Установите зависимость:
   ```bash
   npm install sqlite3
   ```

3. Запустите миграции:
   ```bash
   node db/migrate.js up
   ```

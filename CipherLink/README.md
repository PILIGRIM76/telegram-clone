# CipherLink - Анонимный Мессенджер

🔐 **Secure. Private. Decentralized.**

CipherLink - это современный анонимный мессенджер с расширенным функционалом, обеспечивающий максимальную конфиденциальность и безопасность общения.

## 🔧 Особенности

### Безопасность и Приватность
- **Криптографическая идентификация** вместо номеров телефонов
- **Сквозное шифрование** (E2EE) по умолчанию
- **Zero-knowledge архитектура** - сервер не имеет доступа к данным
- **12-словные seed-фразы** для восстановления аккаунта
- **Открытый исходный код** под лицензией MIT

### Расширенный Функционал (Telegram-like)
- 📱 **Чаты** с текстом, фото, видео, файлами
- 📺 **Каналы** для публичных и приватных обсуждений
- 🛍️ **Магазины** для продажи товаров и услуг
- 👥 **Группы** с ролевой системой управления
- 🎁 **Награды и подарки** внутри системы
- ⏰ **Исчезающие сообщения** с таймером

### Технические характеристики
- **Dumb Server Architecture** - сервер только маршрутизирует сообщения
- **Signal Protocol** для криптографической безопасности
- **WebSocket** для реального времени
- **Responsive Design** для всех устройств
- **Tor/I2P** интеграция для дополнительной анонимности

## 🔐 Как Это Работает

### 1. Создание Идентичности
При первом запуске приложение генерирует:
- Пару криптографических ключей (Ed25519)
- Уникальный UID пользователя
- 12-словную seed-фразу для восстановления

### 2. Безопасное Общение
- Все сообщения шифруются на устройстве отправителя
- Расшифровка происходит только на устройстве получателя
- Сервер видит только зашифрованные данные

### 3. Расширенные Возможности
- **Каналы**: Публичные и приватные обсуждения
- **Магазины**: Онлайн-торговля внутри мессенджера
- **Группы**: Коллективное общение с управлением
- **Подарки**: Внутриигровая экономика

## 🛠️ Технологический Стек

### Frontend
- **React 18** + TypeScript
- **TailwindCSS** для стилизации
- **Framer Motion** для анимаций
- **Zustand** для управления состоянием

### Backend
- **Node.js** + Express
- **WebSocket** для реального времени
- **PostgreSQL** + Redis для хранения
- **MinIO** для файлового хранилища

### Криптография
- **libsodium** для основных операций
- **Signal Protocol** для E2EE
- **X25519** для обмена ключами
- **AES-256** для шифрования данных

## 🔒 Безопасность

### Криптографические Гарантии
- Perfect Forward Secrecy
- Post-Compromise Security
- Certificate Pinning для TLS
- Защита от анализа трафика

### Анонимность
- Отсутствие сбора метаданных
- Интеграция с Tor/I2P
- Скрытие IP-адресов
- Защита от профилирования
